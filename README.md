# 🖥️ Windows Visual Setup Installer

Цей репозиторій містить скрипт, який автоматично:

- Встановлює необхідні програми для персоналізації Windows:
  - Everything Search
  - Flow Launcher
  - Rainmeter
  - TransparentTB
  - Git
- Завантажує готові скіни та налаштування Rainmeter з цього репозиторію.
- Копіює їх у відповідні папки користувача.

---

## 📦 Як використовувати

> 🔒 **Запусти PowerShell від імені адміністратора**!

### 1. Клонуй репозиторій:
```powershell
git clone https://github.com/Kyrylo-Shkinov/personal-desktop-setup.git
cd personal-desktop-setup
```
### 2. Запусти скрипт
```powershell
.\setup.ps1
```
### 3. Налаштуй TranslucentTB та Flow Launcher під свої потреби (рекомндую поставити Everything Search для індексації файлів)
